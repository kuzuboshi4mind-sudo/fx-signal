# FXシグナル

過去のレートから「勝ちパターン／負けパターン」を学習し、世界情勢（通貨の強弱・重要イベント）でふるいにかけて、売買タイミングをリアルタイムで通知するスマホ対応Webアプリです。

> ⚠️ 過去の統計で優位性があった場面を知らせる補助ツールです。将来の利益は保証されません。まずはデモ口座で検証してください。

## 仕組み

1. **学習（バックテスト）**：16種類のパターン（EMAクロス、RSI反転、ボリンジャーバンド回帰／ブレイク、MACDクロス、押し目・戻り、包み足、20本高値・安値ブレイク）を過去データ全体で検出し、「次の足の始値でエントリー、損切り ATR×1、利確 ATR×2（設定で変更可）」で売買したと仮定して勝敗を集計します。
   - 相場環境（順張り／逆張り × トレンド／レンジ）ごとに分けて集計
   - データを前半（学習）と後半（検証）に分け、**両方で成績が良いものだけ**を「勝ちパターン」とします（偶然の好成績を拾わないため）
   - 回数の少ないパターンは期待値を0に寄せて評価（縮小推定）
2. **リアルタイム判定**：足が確定するたびに最新足を判定し、勝ちパターンかつフィルタを通過したものだけを通知します（エントリー・利確・損切り価格、過去勝率、期待値付き）。
3. **情勢フィルタ**
   - 通貨ごとの強弱見通し（-2〜+2）。ペアの見通しと逆向きのシグナルは見送り
   - 重要イベント（米雇用統計は自動登録、そのほかは手動かAI）の前後は見送り
   - **AI分析**：Claude が Web 検索で最新ニュース・中銀発言・指標予定を調べ、通貨の強弱とイベントを提案 → ボタン1つで反映
4. **自動売買（仮想口座）**：仮想の元手（例 3万円）で、シグナル通りに自動で売買します。実際のお金は動きません。
   - 数量は「1回の損切りで失う額＝残高の◯%（初期値2%）」になるよう1000通貨単位で計算し、レバレッジ25倍の上限も守ります
   - 同時に持つポジションは1つ。利確・損切り・最大保有本数で自動決済し、運用時間が来たら全決済して結果を表示します
   - 円の通貨ペア（USD/JPY・EUR/JPY など）で使えます。ページを開いている間だけ動きます
5. **通知**：ブラウザ通知・音・振動。通知したシグナルはその後の利確／損切りを自動で追跡し、実際の勝率を表示します。

## 使い方

1. `index.html` を開く（GitHub Pages で公開: https://kuzuboshi4mind-sudo.github.io/fx-signal/ ）
2. まずは「デモ」データのまま「開始」で動作を確認（模擬相場が2.5秒ごとに1本進みます）
3. 実際のレートを使うには [Twelve Data](https://twelvedata.com/) で無料APIキーを取得し、設定で「Twelve Data」を選んでキーを入力
4. 「設定 → 通知を許可」
5. AI分析を使う場合は「情勢」タブに Anthropic APIキーを入力

APIキーはこの端末のブラウザ（localStorage）にのみ保存されます。

## 注意点

- 通知はページを開いている間だけ届きます（スマホは画面を開いたまま）。閉じていても通知したい場合はサーバー版（LINE／Telegram 通知など）が必要です。
- Twelve Data 無料プランは1日800回・1分8回まで。更新間隔は120秒以上を推奨します。
- デモデータはランダムな模擬相場なので、そこで見つかる「勝ちパターン」に本当の優位性はありません。実データで、検証期間の成績と通知後の実績を必ず確認してください。
